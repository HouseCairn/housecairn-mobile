# Screenshots for the review of the design lot (lot 2d)

Not for merging: this branch only hosts the images shown in the pull request of lot 2d. Each
image puts side by side the web application (reference, its demonstration data, 360 px wide),
the app before lot 2d and the app after it (the golden files of the pull request, with the data
of the test fixture). The "before" panels are drawn by the same golden test on `main` before
the lot, with Noto Sans standing in for the phone's system font.
